# 회계관리 1급 · accounting-pass

회계관리 1급 개인용 기출 학습 사이트. 2023~2026년 30개 회차의 기출 2,400문항과 회차별 답안 MD를 연결했습니다. 2023·2024·2025년은 각 8회차, 2026년은 6회차입니다.

## 실행

Python 3와 Node 22 이상을 사용합니다. Supabase 클라이언트를 번들하므로 먼저 `npm ci`를 실행합니다.

```sh
npm ci
npm run build
python3 -m http.server 5173 --directory dist
```

브라우저에서 http://localhost:5173 을 엽니다. index.html을 파일로 직접 열면 문제 JSON을 불러오지 못할 수 있습니다.

## 구현된 기능

- 회차·과목·유형·검색·미학습 필터, 한 문제씩 풀이
- 제출 전 정답 숨김, 공식 확정답안 기준 즉시 채점 및 답안 출처
- 확신도, 오답·불확실·복습일 도래 문제 모아 풀기
- 확실하게 맞힌 횟수에 따라 1·3·7·14·30일 복습 간격, 오답·불확실은 1일
- 북마크, 메모 자동 저장, 유형 이름 수정
- 현재 문제 이어하기, JSON 기록 내보내기·가져오기
- 모바일 대응, 원문 표·보기 표시

## 자료 및 해설 상태

- sources/: 사용자가 공개를 승인한 기출문제 30개와 답안 30개, 총 MD 60개를 그대로 보존
- scripts/build.py: 문항 분리·답안 연결·자동 유형 분류·안전한 HTML 변환
- dist/questions.json: 2,400문항. 재무회계 1~40번, 세무회계 41~80번
- dist/import-report.json: 원문 누락 점검 결과
- 9월 47·50·55번에는 첨부 MD상 ④ 보기가 없습니다. 임의 복원하지 않고 기본 출제에서 제외했습니다. 2026년 학습 가능 문항은 477개입니다. 전체 연도에서 학습 가능한 문항은 2,393개입니다. 홈에서 누락 원문을 볼 수 있습니다.
- 유형은 규칙 기반 자동 분류 초안입니다. 확정된 전문가 분류가 아니며 문제 화면에서 수정할 수 있습니다.
- 공식 확정답안과 자체 작성한 문제 해설은 별도 표시합니다. 공식 해설은 제공된 자료에 없습니다. 2026년 480문항 각각의 정답 근거 또는 계산 과정을 content/explanations.json에 별도로 작성했습니다. 보기 누락 3문항은 원문 확인 필요 상태이며, 나머지 477문항은 제출 후 개별 해설을 표시합니다. AI API 호출이나 실시간 해설 생성 기능은 없습니다.
- 문제에 기재된 출제연도·세율·일반기업회계기준을 기준으로 학습합니다.
- 같은 문제의 반복 출제 탐지, 전체 과목 분류 검수, 학습 기록의 기기간 동기화와 실전 모의고사는 후속 개발 범위입니다. 메모장 계정 저장 기능은 아래 연결 안내를 따릅니다.

## Netlify 무료 플랜 배포

Netlify는 무료 플랜을 제공하는 호스팅 서비스이며, 오픈소스 소프트웨어 자체는 아닙니다. 무료 제공량과 기능은 계정의 현재 요금제를 확인하세요.

### 방법 1: 바로 올리기

1. 저장소를 내려받고 `python3 scripts/build.py`를 실행합니다.
2. Netlify에서 수동 배포 기능을 선택합니다.
3. index.html이 바로 들어 있는 폴더(dist 내용)를 올립니다.

### 방법 2: GitHub 연결

1. Netlify에 로그인하고 GitHub에서 기존 프로젝트 가져오기를 선택합니다.
2. GitHub 접근 권한을 연결한 뒤 **MANI907/accounting-pass** 저장소를 선택합니다.
3. 배포 브랜치를 `main`으로 설정합니다.
4. 포함된 netlify.toml이 build command `npm run build`, publish directory `dist`를 지정합니다.
5. Python 3를 제공하는 빌드 환경에서 배포합니다. 문제 JSON은 빌드로 생성되므로 위 빌드 명령을 유지하세요. 수동 배포 시에는 로컬에서 먼저 빌드한 dist 폴더를 사용하세요.

**개인용과 비공개는 다릅니다.** 기출문제는 공개 페이지이며, 메모장의 계정 데이터는 로그인과 행 단위 접근 제어로 분리합니다. 일반 정적 배포의 URL에 접근할 수 있는 사람은 문제 파일을 볼 수 있습니다. 비공개 GitHub 저장소만으로 배포 사이트가 비공개가 되지는 않습니다. 호스팅의 접근 제어 지원을 확인하거나, 혼자만 사용하려면 로컬에서 실행하세요. GitHub 공개 저장소에는 사용자 승인에 따라 앱 코드와 첨부 기출 MD 60개가 포함되어 있습니다. 공개 사이트는 https://accounting-pass-sjeon907.netlify.app 입니다. 현재 수동 배포이며 GitHub 수정이 자동 배포되지는 않습니다.

## 기록 저장

풀이 기록·문제별 풀이 노트·분류 수정은 현재 브라우저의 localStorage에 보관합니다. 메모장 탭의 독립 메모는 로그인 전에는 브라우저에, 로그인 후에는 Supabase의 본인 계정에 저장하는 구조입니다. 서버 연결 전에는 로그인 버튼이 비활성화되며 기존 메모를 계속 사용할 수 있습니다. 학습 기록 관리에서 주기적으로 내보내세요. 가져오기는 동일 문항 기록을 덮어씁니다. 정답은 가져온 기록을 신뢰하지 않고 현재 공식 답안과 다시 비교합니다.

## 문제 해설 관리

content/explanations.json의 문항 ID별 text에 개별 해설을 관리합니다. answer는 공식 확정답안과 일치해야 하며, sourceHash는 해당 문항 원문의 SHA-256입니다. 문제 원문 또는 정답이 바뀌면 빌드를 중단하여 기존 해설이 다른 문제에 잘못 연결되는 것을 방지합니다. 자체 작성한 학습용 해설이며 공식 해설이나 전문가 검수본은 아닙니다. 생성형 API 호출 없이 정적 파일로 제공됩니다.

## 시험 전 메모장

북마크 오른쪽 메모장 탭에서 제목·본문을 작성하고 자동 저장합니다. 제목·본문 검색, 수정, 삭제를 지원하며 최대 1,000개, 제목 120자, 본문 20,000자까지 저장합니다. 로그인 전 메모는 각 브라우저의 localStorage에 보관합니다. 로그인 후에는 본인 계정에 보관하며 다른 계정에 노출되지 않도록 RLS를 적용합니다. 새 백업(v2)에 문제 기록과 메모장이 함께 포함됩니다. 기존 백업(v1)은 현재 메모장을 건드리지 않으며, v2를 가져올 때 같은 ID의 메모는 수정시각이 더 최신인 내용을 유지합니다. 브라우저 저장소 삭제 시 기록이 사라지므로 기기 이동 전 내보내세요.

## 2023~2025년 기출 추가

- 추가 문제 24회차 1,920문항, 기존 포함 30회차 2,400문항입니다. sources에는 문제·답안 총 60개 MD가 있습니다.
- 홈에서 연도를 선택하고, 문제 풀이에서 연도·월·과목·유형으로 필터링합니다.
- HTML 표, Markdown 표, 한 줄 텍스트 답안을 지원합니다. 2024년 3월 세무회계 답안은 1~40번으로 다시 시작하므로 문제의 41~80번에 대응시킵니다.
- 2025년 6월 46·55·76·78번과 기존 2026년 9월 47·50·55번은 ④ 보기 누락으로 기본 출제에서 제외합니다. 학습 가능 문항은 2,393개입니다.
- 이전 연도 세법은 출제 당시 조건을 유지하며, 현행 법령에 맞게 원문이나 공식 답안을 임의 변경하지 않습니다.
- 2026년 개별 해설 480개는 유지합니다. 신규 회차의 개별 해설은 작성 전이며 동일 재무회계 문항의 원문·보기·정답이 일치할 때만 기존 해설 연결을 허용합니다. 미작성 문항은 채점 후 해설 작성 전임을 표시하며 범용 개념 요약으로 대체하지 않습니다.
- 기존 2026년 문항 ID를 그대로 유지하여 풀이·북마크·풀이 노트·메모장과 v1/v2 백업 호환성을 보존합니다.


## 계정 메모 저장 연결

구현은 완료했으며 실제 Supabase 프로젝트 생성은 사용자의 조직 선택을 기다립니다. 아직 서버 저장이 활성화된 상태가 아닙니다.

- `database/cloud-memos.sql`: 본인 계정만 SELECT/INSERT/UPDATE할 수 있는 RLS, 버전 조건부 수정, 삭제 동기화용 tombstone. 브라우저에서 `service_role` 키를 사용하지 않습니다.
- `dist/cloud-config.json`: Supabase 프로젝트 URL과 **publishable key**만 설정합니다. 두 값은 공개 클라이언트 설정이며 비밀키를 넣으면 안 됩니다. 비어 있으면 기존 브라우저 메모 기능을 유지합니다.
- `src/cloud-client.mjs`, `scripts/build-web.mjs`: 고정 버전 Supabase SDK를 로컬 번들합니다. `npm ci && npm run build`로 배포 파일을 생성합니다.
- 프로젝트의 Auth URL Configuration에서 Site URL을 `https://accounting-pass-sjeon907.netlify.app`으로 설정하고 Redirect URLs에 `https://accounting-pass-sjeon907.netlify.app/`을 허용해야 가입 확인·비밀번호 재설정 링크가 이 사이트로 돌아옵니다. 이메일/비밀번호 가입과 이메일 확인을 사용합니다. Supabase 기본 메일 발송은 조직 구성원 주소로 제한될 수 있어 타인 가입을 확대할 때 별도 SMTP 설정이 필요합니다.
- 메모장 → 로그인/가입 → **계정으로 복사**로 브라우저 메모를 가져옵니다. 원본 브라우저 메모는 유지하며 같은 원본은 중복 복사하지 않습니다. 다른 기기는 같은 이메일로 로그인합니다.
- 서버 응답을 확인한 뒤에만 `계정에 저장됨`을 표시합니다. 네트워크 오류 시 계정별 캐시에 대기 중 편집을 보관하고 재연결·창 활성화·30초 주기로 재시도합니다. 서버 저장 완료 전 브라우저 데이터를 지우면 대기 내용은 사라질 수 있습니다.
- 동시에 수정하면 서버의 최신 내용을 유지하면서 로컬 편집을 `(기기 사본)`으로 추가합니다. 오래된 기기의 삭제가 최신 수정본을 지우지 않도록 합니다. 로그아웃한 계정의 캐시는 다른 계정에 표시하거나 전송하지 않습니다.
- 백업 v2는 현재 열려 있는 메모장의 내용을 포함합니다. 계정에 로그인한 상태에서 백업을 가져오면 해당 계정의 저장 대기열에 추가합니다. 풀이 기록·북마크·문제별 풀이 노트는 계속 브라우저별로 관리합니다.
- 현재 20개 단위 테스트와 DOM 회귀 검증은 통과했습니다. 실제 Auth 왕복·원격 DB 접근권한 검증은 프로젝트 연결 후 수행해야 합니다.
