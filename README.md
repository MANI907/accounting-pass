# 회독 · accounting-pass

회계관리 1급 개인용 기출 학습 사이트. 2026년 1·3·5·6·7·9월 기출 480문항과 회차별 공식 확정답안 MD를 연결했습니다.

## 실행

Node 패키지 설치나 API 키는 필요 없습니다. Python 3, 검증용 Node 18 이상을 사용합니다.

```sh
python3 scripts/build.py
python3 -m http.server 5173 --directory dist
```

브라우저에서 http://localhost:5173 을 엽니다. index.html을 파일로 직접 열면 문제 JSON을 불러오지 못할 수 있습니다.

## 구현된 기능

- 회차·과목·유형·검색·미학습 필터, 한 문제씩 풀이
- 제출 전 정답 숨김, 공식 확정답안 기준 즉시 채점 및 답안 출처
- 확신도, 오답·불확실·복습일 도래 문제 모아 풀기
- 확실하게 맞힌 횟수에 따라 1·3·7·14·30일 복습 간격, 오답·불확실은 1일
- 북마크, 메모 자동 저장, 유형 이름 수정
- 현재 문제 이어하기, JSON 기록 내보내기·가져오기
- 모바일 대응, 원문 표·보기 표시

## 자료 및 해설 상태

- sources/: 사용자가 공개를 승인한 기출문제 6개와 확정답안 6개, 총 MD 12개를 그대로 보존
- scripts/build.py: 문항 분리·답안 연결·자동 유형 분류·안전한 HTML 변환
- dist/questions.json: 480문항. 재무회계 1~40번, 세무회계 41~80번
- dist/import-report.json: 원문 누락 점검 결과
- 9월 47·50·55번에는 첨부 MD상 ④ 보기가 없습니다. 임의 복원하지 않고 기본 출제에서 제외했습니다. 실제 학습 가능 문항은 477개입니다. 홈에서 누락 원문을 볼 수 있습니다.
- 유형은 규칙 기반 자동 분류 초안입니다. 확정된 전문가 분류가 아니며 문제 화면에서 수정할 수 있습니다.
- 공식 확정답안과 학습 보조 개념 요약은 별도 표시합니다. 공식 해설은 제공된 자료에 없습니다. 9월 72번에만 별도 작성한 문항 해설이 있으며, 나머지 문항의 선택지별·계산별 해설은 아직 없습니다. AI API 호출이나 실시간 해설 생성 기능은 없습니다.
- 문제에 기재된 출제연도·세율·일반기업회계기준을 기준으로 학습합니다.
- 같은 문제의 반복 출제 탐지, 전체 과목 분류 검수, 로그인·기기간 자동 동기화, 실전 모의고사는 후속 개발 범위입니다.

## Netlify 무료 플랜 배포

Netlify는 무료 플랜을 제공하는 호스팅 서비스이며, 오픈소스 소프트웨어 자체는 아닙니다. 무료 제공량과 기능은 계정의 현재 요금제를 확인하세요.

### 방법 1: 바로 올리기

1. 저장소를 내려받고 `python3 scripts/build.py`를 실행합니다.
2. Netlify에서 수동 배포 기능을 선택합니다.
3. index.html이 바로 들어 있는 폴더(dist 내용)를 올립니다.

### 방법 2: GitHub 연결

1. Netlify에 로그인하고 GitHub에서 기존 프로젝트 가져오기를 선택합니다.
2. GitHub 접근 권한을 연결한 뒤 **MANI907/accounting-pass** 저장소를 선택합니다.
3. 배포 브랜치를 `main`으로 설정합니다.
4. 포함된 netlify.toml이 build command `python3 scripts/build.py`, publish directory `dist`를 지정합니다.
5. Python 3를 제공하는 빌드 환경에서 배포합니다. 문제 JSON은 빌드로 생성되므로 위 빌드 명령을 유지하세요. 수동 배포 시에는 로컬에서 먼저 빌드한 dist 폴더를 사용하세요.

**개인용과 비공개는 다릅니다.** 이 버전에는 로그인·서버 접근 제어가 없습니다. 일반 정적 배포의 URL에 접근할 수 있는 사람은 문제 파일을 볼 수 있습니다. 비공개 GitHub 저장소만으로 배포 사이트가 비공개가 되지는 않습니다. 호스팅의 접근 제어 지원을 확인하거나, 혼자만 사용하려면 로컬에서 실행하세요. GitHub 공개 저장소에는 사용자 승인에 따라 앱 코드와 첨부 기출 MD 12개가 포함되어 있습니다. Netlify 사이트 배포는 별도 단계입니다.

## 기록 저장

풀이 기록·메모·분류 수정은 현재 브라우저의 localStorage에만 보관합니다. 서버로 보내지 않으며 브라우저 저장소 삭제·다른 브라우저·기기에서는 이어지지 않습니다. 학습 기록 관리에서 주기적으로 내보내세요. 가져오기는 동일 문항 기록을 덮어씁니다. 정답은 가져온 기록을 신뢰하지 않고 현재 공식 답안과 다시 비교합니다.
